# 光调 · 本地 AI 调色工作台

一款本地优先的单页照片调色应用。照片只在浏览器中处理，AI 支持浏览器直连用户自行配置的 OpenAI 兼容 Chat Completions 服务，也保留原有 Node 代理方式。

## 在线使用与 GitHub 部署

网页地址：[光调在线修图](https://dian-wa.github.io/lightune-photo-editor/)。源码仓库：[Dian-Wa/lightune-photo-editor](https://github.com/Dian-Wa/lightune-photo-editor)。

GitHub Pages 版本支持照片导入、86 项调整、内置／自定义模板、撤销与对比、JPG／PNG／WebP 导出，以及模板备份。照片仍在浏览器本地处理。

在「AI 调色灵感 → AI 服务配置」中选择「浏览器直连」，填写 HTTPS 接口地址（含 `/v1` 等服务商要求的路径，或完整 `/chat/completions` 地址）、个人 API 密钥和模型 ID，然后点击「生成配方」。无需部署后端。服务商必须允许浏览器跨域请求（CORS，包括 Authorization 请求头）；网络错误不能仅凭前端区分为 CORS 或连接故障，应用会给出排查提示。

密钥只保留在当前页面内存中，默认隐藏，刷新页面后需重新填写；不会进入模板、备份或浏览器存储。「记住地址和模型」仅保存非敏感配置。请只填写信任的 HTTPS 服务地址，密钥会直接发送到该地址。JSON 模式默认关闭，仅当服务商支持 `response_format` 时勾选。请求最多等待 60 秒，可手动取消；不会自动重试产生额外调用。

GitHub Pages 无法运行 `server/index.ts`。需要原有代理方式时，可在本机运行 Node 服务，或配置下述独立后端，再在调用方式中切换至「原有代理」。

仓库的 `.github/workflows/deploy-pages.yml` 会在推送到 `main` 后自动安装锁定依赖、运行测试、构建并发布网页。仓库 Settings → Pages 的 Source 需设为 GitHub Actions。构建会自动使用 Pages 提供的仓库子路径。

如以后部署独立 AI 后端，可在仓库 Settings → Secrets and variables → Actions → Variables 中填写公开的 `VITE_API_BASE_URL`（例如 `https://your-backend.example.com`），然后重新运行工作流。此地址对应后端的 `/api/recipes/generate` 接口；后端还需配置网页来源的 CORS、访问控制和调用额度。`OPENAI_API_KEY` 只配置在该后端，不能放入 `VITE_*` 变量或前端代码。

本机 `.env`、部署认证工具及缓存不进入仓库；用户照片与 IndexedDB 模板不会随源码上传。

## 启动

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
# 在记事本中填写服务端密钥并保存；不配置也可使用手动调色功能
# 首次使用且没有 node_modules 文件夹时，先运行 npm.cmd install
npm.cmd run dev
```

打开 `http://127.0.0.1:5173`。本地 AI 代理运行在 `http://127.0.0.1:8787`。

## 主要功能

### 第一阶段升级

轻首页提供照片导入、体验样片、模板入口和继续草稿。照片导入后进入手机优先编辑器，底部为模板、滤镜、调节、构图、AI 和更多；顶部“保存”集中提供导出图片、保存草稿与另存模板。桌面继续使用三栏布局。

调色、独立滤镜及构图共用最多 60 步撤销历史。工具支持应用和取消，切换工具自动提交预览。常用调节优先显示八个参数，“全部”保留 24 个类别。一次滑块拖动只提交一条历史。构图支持直接拖动八个控制点、90° 旋转、水平/垂直翻转、±45° 拉直，拉直自动安全放大避免黑边。查看支持双指缩放、放大后拖动和双击适应画布，不影响导出尺寸。

只有主动点击“保存草稿”才会把原图 Blob 与完整编辑文档保存到 IndexedDB；同一草稿后续自动更新。未主动保存的原图不会持久化。草稿与模板分开：模板不包含照片或构图，新模板可携带独立滤镜强度，旧 JSON 模板继续兼容。文本 AI 不接收照片，密钥不进入草稿。云端图像 AI 尚未开放。

### 第二阶段：创作与局部修图

从“更多”进入“文字 · 贴纸 · 边框”或“局部修图”，桌面工具栏也提供独立入口。文字支持字体、字号、颜色、对齐、描边及透明度；文字和导入贴纸均可在图片上移动、缩放和旋转。图层支持排序、隐藏、复制和应用内回收站恢复。边框支持纯色、宽度和留白比例。

局部修图支持多个画笔、线性渐变和径向蒙版，提供擦除、羽化、反选及曝光、对比度、饱和度、色温、清晰度和柔化。蒙版跟随原照片内容，构图改变后仍保持对应区域。创作和局部修图期间关闭原图对比手势，退出后恢复。

所有操作接入撤销、重做、工具应用与取消、图片导出及本地草稿。草稿包含贴纸资源；模板仍仅保存调色配方，不包含图层、蒙版或用户照片。全部处理在本地完成，不新增照片上传。

### 第三阶段：免费本地人像修图

手机“更多 → 人像修图”、桌面“人像”打开。点击“识别人脸”后才加载同源托管的 MediaPipe 模型与 WASM，在独立 Worker 中定位至多 5 张脸；不识别身份，不发送照片，不需要 API 密钥，没有按次调用费。首次模型及运行文件下载会消耗流量，浏览器缓存被清除后需要重新加载；设备性能、托管免费额度与缓存可用性仍有限制。

自动区域为脸部轮廓，尽量排除眼睛、眉部和嘴唇，并非精确的全身皮肤语义分割；侧脸、遮挡、暗光和远距离照片可能失败或选区不准。使用“显示蒙版”检查范围；“补画皮肤／擦除皮肤”可修正，识别不可用时仍可“添加手动皮肤区域”。重复识别会新增区域并保留之前的编辑，可移除不需要的区域或撤销。

每个区域独立支持保边柔肤、肤色亮度、冷暖、色调和饱和度，默认参数全部为零，不自动美白。区域跟随原图坐标，支持构图后继续编辑；可撤销、重做、取消整个工具，保存草稿后可恢复人像参数与修正笔画。调色模板不保存人像区域。该阶段不提供祛痘、身体塑形、生成式消除或云端图像编辑。

安装依赖后 `npm run dev` / `npm run build` 会先复制固定版本运行资产，生产构建同时验证模型 SHA-256。模型来源、版本和各组件许可见 [NOTICE](public/models/portrait/NOTICE.md)；完整上游许可见 [LICENSE](public/models/portrait/LICENSE.txt)。

- 内置、自定义和 AI 调色模板
- JPG / PNG / WebP 本地导入与导出
- 前后对比、按住看原图、撤销、重做、重置
- IndexedDB 模板持久化、JSON 备份与恢复
- 模板缩略图、复制、重命名、收藏与回收站
- 导出尺寸/体积预估和隐私优先的元数据清理

## 精细与专业调整

右侧「手动调整」现在有 86 项参数，按九个模块分组。常用光照、色彩、质感默认展开，专业工具点击标题展开。

- 光照新增白色色阶、黑色色阶和中间调；色彩新增整体色相；质感新增清晰度与褪色感。
- 单色细调 HSL：选择红、橙、黄、绿、青、蓝、紫或洋红，再分别调节色相、饱和度、明度。
- 曲线：RGB 总曲线与红／绿／蓝独立通道。五个固定输入控制点支持上下拖动，或选择输入点后填写 0–255 的输出值；键盘上下键调整 1，Shift+上下键调整 10。拖动一次是一条撤销记录。
- 色彩分级：阴影、中间调、高光分别设置色相与饱和度，混合与平衡控制区域过渡。
- 黑白混色：先提高黑白强度，再按原始颜色调整转换后的明度。
- 暗角支持中点、圆度、羽化；颗粒支持大小和粗糙度，噪声图案保持确定性。

滑杆旁的数字可直接输入，按 Enter 或离开输入框生效，Esc 取消当前输入。每组「开启」按钮可暂时关闭效果并保留参数，回转箭头只重置该组。所有高级参数与开关支持模板保存、AI 配方、会话恢复和 JSON 备份；旧模板会补齐默认参数。

曲线采用固定五点的平滑插值，清晰度采用局部亮度反差算法。手机端采用顶部常驻预览和底部工具栏：滤镜显示内置预设，模板显示自定义模板，调色、裁剪、AI 与导出各有独立面板。裁剪支持自由比例、常用固定比例、拖动选框及位置/大小调整；应用后会同步影响原图对比预览和原尺寸导出，切换模板不会清除当前照片的裁剪。裁剪范围只属于当前照片，不写入调色模板或图片会话。降噪与透视校正仍属于后续功能。
